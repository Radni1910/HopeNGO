# NGO Management System - React Version

## Stack
- React + Vite
- Node.js + Express
- MySQL

## Run
1. Open the project in VS Code.
2. Create the database using `database.sql` if needed.
3. Backend:
   `cd backend`
   `npm install`
   `copy .env.example .env`
   `npm start`
4. Frontend in a second terminal:
   `cd frontend`
   `npm install`
   `npm run dev`
5. Open http://localhost:5173

Default demo login: admin / admin123

If your MySQL root password is different, edit `backend/.env`.
